# 🤝 Contributing to IMB Research Pipelines

We welcome contributions, bug reports, and computational workflow improvements from collaborators and researchers.

## Guidelines
1. **Branching:** Create feature branches from  / .
2. **Reproducibility:** Ensure scripts (R, Python, Nextflow) include complete package dependencies and random seeds.
3. **Data Integrity:** Do not commit proprietary raw patient datasets without de-identification.
4. **Pull Requests:** Open a PR describing changes and validation tests.
